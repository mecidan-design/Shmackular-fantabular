# Shmackular Fantabular Landlord Simulator

English board game (A2, 5th form) for 2 to 5 players on one computer.
Play online: https://mecidan-design.github.io/Shmackular-fantabular/

One self-contained `index.html`: it also works offline with a double click.

Copyright Prof Dan M. Mecikovsky

## Phones and tablets

The game now adapts to touch screens. It scales the whole pixel interface to the screen size and has a portrait layout (board on top, controls and teams below). It also works in landscape, which gives the biggest board. On a phone, "Full screen" in the pause menu hides the browser bars.
